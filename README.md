# RegexTester
Coding Languages: HTML / CSS / JS | Category: Utility

This is a simple Regex Tester

**-- How it Works --**

- Built with _Html_, _CSS_, _JS_
- The highlighted text is using your input & regex and displaying it behind your input field

**--**

**-- Usage --**

1. Open:
  [Use!](https://alfieofrosehouse.github.io/RegexTester/)
2. Type in your regex, and your input will automatically be highlighted to show what it matches
3. Regex can be written as: _/pattern/key_ or _pattern/key_ or _pattern_
